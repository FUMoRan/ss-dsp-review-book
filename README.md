# 📡 S&S · DSP 复习本

一个**完全本地、纯离线**的《信号与系统》/《数字信号处理》错题与知识点复习网站。
无需注册、无后端、无云端上传，所有数据都保存在你自己的浏览器里。

两门课在同一个站点内用顶部按钮切换：**连续 · S&S** 与 **离散 · DSP**。

在线使用：https://fumoran.github.io/ss-dsp-review-book/

> 手机上可用浏览器「安装应用 / 添加到主屏幕」，安装后即为全屏应用，
> 断网也能正常复习。

## 主要功能

- **错题库 + 知识点库**双库分离，标签共用；解析与知识点默认折叠
- **科目分区**：S&S（连续）/ DSP（离散）一键切换，条目的 `subject` 字段决定归属
- 支持粘贴 AI 按固定格式生成的题目**批量导入**
  （`【题目】/【解析】/【知识点】/【代码】/【我的错误答案】/【标签】`，多题用 `===` 分隔）
- KaTeX 公式渲染、**图片上传与压缩**（存 IndexedDB）、导入**去重**提示
- **📐 速查表**：常用**变换对**（CTFT / 拉普拉斯 / Z / DFT，29 条）、
  **变换性质**（14 条）、**连续 ↔ 离散对照**（卷积、系统函数、稳定判据、采样等 9 组），可搜索
- **📈 绘图**（纯 Canvas，无第三方库）：
  时域波形、离散杆图、**频谱**（幅度 / 相位）、**幅频相频（Bode）**、
  **零极点图**（自动判稳）、**卷积图解动画**（反转 → 平移 → 相乘 → 积分）
- **代码高亮**：解析里的 MATLAB / Python 代码块自动识别语言并着色，可一键复制
- **公式快捷插入条**、**学科预设标签**（按 S&S / DSP 分组的常用术语一键打标）
- ⭐ 收藏、多标签交集筛选、背题模式、随机一题、返回顶部、长按多选
- 搜索扩展：`tag:` / `status:` / `star` / `due` / `has:img` / `has:code` 前缀 + 全文关键词
- **图形体验**：剪贴板 / 拖拽粘贴图片、配图编号与排序、卡片大图模式、
  多图**灯箱**（翻页 / 缩放 / 旋转 / 拖动）
- **回收站**（软删除 + 30 天自动清理）、JSON 导出导入、完整备份（含图片）、
  Markdown 导出、打印、**孤儿图片 GC**
- 可自定义**分栏 / 主题 / 密度 / 动效 / 卡片配图大小**，适配手机、平板横屏与桌面
- **AI 识题**（可选）：拍照上传题目，由你自选的 AI 服务商识别并整理成字段，核对后导入；
  也可一键复制**学科化提示词**，拿去任意对话式 AI 里预处理

## 数据与隐私

除「AI 识题」外，所有内容仅存于浏览器本地（`localStorage` + `IndexedDB`），不上传任何服务器。

「AI 识题」是唯一需要联网的功能：使用它时，**题目图片会发送到你自己选择并配置的
AI 服务商**（API Key 只保存在本机浏览器，不写入备份文件、不进仓库）。不使用该功能
时，应用完全离线可用。

换设备或清理浏览器数据会丢失内容，请**定期使用「导出」备份**。
